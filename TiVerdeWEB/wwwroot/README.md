# TI VERDE

Projeto acadêmico desenvolvido para representar uma ONG voltada à preservação do meio ambiente.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Estrutura

O projeto utiliza uma SPA (Single Page Application), com navegação dinâmica entre as páginas e organização do código em módulos JavaScript.

## Versionamento

O projeto utiliza GitFlow, com branches `main`, `develop`, `feature/` e `hotfix/`.

A primeira versão estável está identificada pela tag `v1.0.0`.
